## 作品简介（500 字以内）

“狗头军师”是一款帮普通人处理感情困惑的 Agent。遇到暧昧、忽冷忽热、吵架或双方付出不对等时，很多人不是缺一句漂亮话，而是分不清哪些是事实、哪些只是自己猜的，也不知道下一步该做什么。狗头军师先听用户把话说完，再帮用户理清已经知道的、可能是怎样的、还不知道的，然后给出一条能直接去做的建议：怎么说、观察多久、出现什么情况就停下。用户自己决定要不要做，系统不会替用户发消息。用户可以临时问，不留长期记录；也可以给最多 5 个人分别建档，聊天、证据和记忆不会混在一起。关系进展用 K 线展示，但只记录已经发生的事情：红色是有进展，绿色是退缩或冲突，灰色是证据不够，不会预测对方爱不爱或成功率。公开案例不用 API Key，也不用真实聊天；需要时可以接入 DeepSeek。系统会先确认聊天双方是谁，发现对不上就立即停止；不破解聊天数据库、不后台监控、不自动联系任何人。目前已有可运行 Demo、电脑和手机界面、10 项测试和完整说明。这套方法也能用在其他“情绪很重、又很难判断”的个人问题上。

## 一次完整使用是怎样的

1. 用户像平时聊天一样说出困惑，可以只问这一次，也可以给这个人建档。
2. 狗头军师先听懂用户在难受什么，再分清哪些是真的、哪些只是猜的、哪些还不知道。
3. 如果用户贴了聊天记录，系统会先确认谁是用户、谁是对方；发现前后对不上就停下来。
4. 狗头军师建议继续、问清、修复或离开，并给出可以直接复制的话、要观察多久、什么情况应该停。
5. 用户自己决定要不要采用，系统不会自动发消息。
6. 后续发生的事情只放进这个人的档案，并在 K 线里标出来源。
7. 用户可以随时改正、撤回、暂停记忆，或者归档不再关注的人。

## 和普通聊天机器人哪里不一样

- **不只陪聊，还会走到下一步**：每次建议都说清楚要做什么、看多久、什么情况该停。
- **图表只讲发生过的事**：K 线不猜爱不爱，也不算成功率。
- **每个人的资料分开放**：最多建 5 个档案，聊天、记忆和证据不会串到别人身上。
- **先确认聊天里谁是谁**：有账号和发送人信息就优先使用；没有就请用户确认，前后冲突马上停。
- **用到哪，查到哪**：每次只取当前问题需要的少量狗头军师资料，不把全部内容塞进对话。
- **真的接入 DeepSeek Harness**：对话、模型、工具和页面都使用官方底座，不是做一个长得像的页面。

## 现在做到哪了

- 公开假数据无需 API Key 和真实聊天，也能从提问一直演示到用户确认下一步。
- DeepSeek API Key 与自定义模型提供方能力保留在官方设置中。
- 16 根证据 K 线支持 OHLC、价格轴、成交量、十字线、悬停证据与右侧决策面板。
- 自动化测试覆盖人数上限、资料不串档、身份对不上就停止、记忆撤回和归档恢复。
- `pnpm run test:all`：10/10 通过；`pnpm run check:readonly`：通过。
- 浏览器 QA 覆盖桌面聊天、桌面 K 线、模型设置、归档流程与移动端布局。

## 隐私和安全

- 公开仓库不包含真实聊天、凭据、Token、Cookie 或私密文件。
- 原始聊天属于本地证据层，不进入长期记忆；长期记忆仅保留五类精简记录。
- 不解密聊天数据库、不绕过系统权限、不后台监控、不自动发送消息。
- 高风险动作必须由用户确认；身份冲突、明确拒绝与安全风险均触发停止或转入安全路由。

## 别人可以怎么拿去用

项目把可以重复使用的部分单独做好：接入 DeepSeek 的方式、按问题查资料的方法、确认聊天双方的规则、证据图和记忆处理。其他“情绪很重、又很难判断”的个人问题，也可以直接使用“先看清事实，再决定行动，之后观察结果”的方法，不必从头开发。
