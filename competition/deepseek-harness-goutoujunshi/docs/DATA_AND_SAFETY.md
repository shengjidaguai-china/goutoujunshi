# 数据与安全说明

## 默认数据策略

- 项目自带 Demo 只包含公开合成数据，不包含开发者或用户的真实聊天、联系方式、凭据或私密文件。
- 浏览器 Demo 状态只保存在当前浏览器的 `localStorage`；Harness profile 与记忆运行数据只写入本项目 `.runtime/`，该目录不会提交。
- “临时问问”的消息明确不写入 `localStorage` 或长期记忆；刷新页面或切换 Harness 会话后清空。
- 原始聊天、截图和导出文件属于本地证据层，不进入长期记忆。长期记忆只保存提炼后的 `user`、`object`、`relationship`、`event`、`hypothesis` 五类记录。
- 用户可查看、更正、暂停、恢复、撤销和删除自己的长期记忆；关键动作保留可撤销操作记录。
- 归档对象不是删除：它只把对象移出活动列表，并保留稳定 ID、会话、证据、记忆和任务以便恢复；真正删除仍需明确的删除动作。

## 身份映射与“防认反”

1. 优先使用 sender/member ID、账号和会话元数据。
2. 不根据左右气泡、姓名、性别、头像或语气猜身份。
3. 元数据不足时必须让用户确认至少一条锚点消息，随后锁定映射。
4. 跨批次发现同一 sender ID 角色冲突时立即暂停，不覆盖旧映射，不继续生成关系判断。
5. 每个关系事件保存对象 ID、sender ID、消息摘要、来源批次/消息引用与证据完整度。

## 授权边界

聊天记录不是必选输入。用户需要时可以主动粘贴、上传截图/导出文件、接入 ChatLab，或明确授权 Agent 对任意聊天平台做本机只读查看。本项目明确禁止：

- 解密或直接读取受保护的聊天数据库；
- 绕过操作系统、应用或平台权限；
- 后台监控聊天或持续抓取；
- 未经当次确认自动发送消息、自动联系对象；
- 将真实聊天、密钥、token、cookie 或其他凭据写入仓库。

## 关系判断边界

关系进展图只解释已记录的可观察证据。颜色含义固定为：红色正向进展、绿色退缩/冲突/投入下降、灰色证据不足。它不预测爱意、忠诚、人格、关系成败或任何成功率。

军师建议始终区分事实、合理推测和未知，给出观察窗口与停止条件，并在采取行动前保留人工确认。若出现威胁、跟踪、暴力、自伤或其他安全风险，应停止普通关系推进建议，转入既有 Skill 的安全与危机路由。
