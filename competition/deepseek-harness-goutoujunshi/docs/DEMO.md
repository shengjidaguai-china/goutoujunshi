# 公开 Demo 演示脚本

全部姓名、sender ID、消息、时间与证据均为公开合成数据。

## 主路径（约 3 分钟）

1. 启动后先点“临时问问”：输入任意公开问题，确认页面像普通 Agent 对话，文案明确“不建档 · 不写长期记忆”；刷新后临时消息清空。
2. 点击“载入公开案例”：左侧出现“小北”和“阿岚”，内部 ID 稳定且两个对象的会话、证据、任务和精简记忆隔离。
3. 在“小北”对话里顺着读一段自然回复：先承接情绪，再把已知事实、合理判断和未知揉进对话，给出低压力话术、48 小时观察窗口和停止条件；只有用户点“采用这一步”才记录确认，不自动发送。
4. 切换到“阿岚”：不出现“小北”的聊天或证据。
5. 切回“小北”→“关系进展”：先指出 16 根公开证据 K 线，以及周期栏、指标栏、OHLC、价格轴、当前价线、成交量和右侧决策面板；悬停红、绿、灰 K 线，右侧实时显示事实、消息摘要、来源与完整度。图只解释记录，不预测爱意或成功率。
6. 点击输入框左侧 `+`：按需粘贴、选择截图/文件、ChatLab 或电脑只读；演示 `contact_17` 跨批次角色冲突时立即停止且不覆盖映射。
7. 点击“归档这段关系”并确认：对象移出活动列表并回到“临时问问”；在“已归档”中可恢复，数据不丢失。
8. 点击左下角“模型连接”：确认弹窗只显示模型提供方，DeepSeek API Key、添加提供方、自定义提供方均可操作；通用设置、插件和 Agent 预设不再占用产品界面。公开案例本身仍无需 Key。

## 建档与五对象上限

从临时模式点击“建立关系档案”，输入任意公开代号。重复建立到 5 个后按钮会拒绝第 6 个对象；改名只改变显示代号，不改变内部 ID。归档后活动对象名额释放，恢复时仍受 5 个上限约束。
