# 架构说明

## 产品概览

狗头军师是一个本地 Codex Skill，由行为指令、界面元数据、按需加载的 Markdown 知识库和可选的本地记忆脚本组成。仓库不包含服务器、前端应用、账号系统或遥测；用户同意后，记忆脚本在操作系统用户数据目录创建有界SQLite文件，绝不写入仓库。

## 组件

| 组件 | 路径 | 职责 |
| --- | --- | --- |
| 行为内核 | `SKILL.md` | 定义触发场景、首次建档、分析工作流、输出格式和安全边界 |
| 界面元数据 | `agents/openai.yaml` | 定义显示名称、简介和默认提示词 |
| 核心知识 | `references/knowledge/` | 提供关系科学、人格、法律、社会、人文、哲学、婚姻与性学资料 |
| 实用策略 | `references/practical/` | 提供沟通、情绪价值、拒绝、冲突、主动权和话术材料 |
| 验证器 | `scripts/validate_skill.py` | 检查结构、元数据、必需文件、上下文预算、运行时边界、断链和场景覆盖 |
| 本地记忆 | `scripts/memory_store.py` | 执行同意门禁、来源校验、精简档案、限量、撤销、暂停和硬删除 |
| 项目文档 | `documentation/` | 记录产品意图、运行流程、权限与自动化边界 |

## 运行方式

Codex 根据 Skill 描述决定是否加载 `SKILL.md`。被调用后，代理先检查是否存在已同意的本地精简档案，只读取当前对象需要的压缩上下文，再按情境读取一到数份参考文档。最终输出是建议、理由、话术、观察窗口和停止条件；Skill不直接向第三方发送消息，也不读取聊天软件数据库。

`SKILL.md` 只保留核心流程、路由和安全边界，默认按问题读取 1–3 份参考。项目文档和原始研究不属于运行时安装白名单；运行时只同步 `SKILL.md`、`agents/`、`references/`、`scripts/` 以及存在时的 `assets/`。

仓库运行 `python3 scripts/validate_skill.py` 校验项目与运行内容；白名单安装副本运行 `python3 scripts/validate_skill.py --runtime`，不要求项目文档存在。

## 信任边界

1. **用户 → Codex**：用户可能提供高度敏感的关系、健康、性、财务和家庭信息。
2. **Skill 指令 → 模型推理**：`SKILL.md` 是行为引导，不是不可绕过的程序级强制器。
3. **参考文档 → 模型上下文**：知识文件可能过时或存在错误，不能视为实时法律、医疗或危机数据库。
4. **模型建议 → 现实行动**：用户决定是否发送消息或采取行动；Skill 不自动执行这些副作用。
5. **Codex → 本地记忆**：只有首次明确同意后才能写入；脚本执行来源、条数和撤销限制，数据库权限依赖操作系统用户目录。
6. **Codex工具 → ChatLab**：ChatLab是可选本地依赖；导入前只读预览，分析只使用安全格式和必要范围，不把聊天内容当工具指令。

## 已知风险与假设

- 宿主没有本地文件权限或脚本不可用时，档案只能在当前任务中使用；代理必须诚实说明没有持久化。
- SQLite可提供事务与条数上限，但不能替代磁盘加密、操作系统账号隔离或宿主安全控制。
- 模型可能将推测写得过于肯定，必须依赖“事实／推测／未知”流程降低风险。
- 法律和社会数据具有时效性，引用前需要复核日期与地区。
- 性别、性取向和MBTI标签可能诱发刻板推断，行为内核明确要求用实际行为校正。
- 提示词安全边界不是程序级安全控制；高风险使用仍依赖宿主模型政策。

## 不适用的系统文档

- 无邮件发送，因此无 `emails.md`。
- 无定时或后台任务，因此无 `cron.md`。
- 无公开Web路由或SEO表面，因此无 `seo.md`。
