# 公开表达案例的伦理转译

## 来源定位

- **北疯小同学**：公开内容以直播连麦、即兴接话、诗词化情话、幽默和临场口才为主。大量网络材料是切片或二手语录，不视为作者课程、心理学事实或可核验名言库。
- **鄙人李洋洋**：公开内容覆盖主动表达、聊天破冰、暧昧推进、约会、关系维护和分手心态。属于创作者经验和娱乐化表达，不是关系科学研究。

只参考创作者本人公开发布或能确认来源的内容；不收录盗版课程、付费内容搬运、完整逐字稿或无法确认归属的“经典语录”。

公开核对入口（2026-08-02复核）：[北疯小同学公开资料](https://www.baike.com/wikiid/7431861350086213673)、[鄙人李洋洋B站作品检索](https://search.bilibili.com/all?keyword=%E6%9D%8E%E6%B4%8B%E6%B4%8B)、[本人发布的《恋爱掌握主动权》](https://www.bilibili.com/video/BV1dC4y1K7cm/)。北疯内容若只能找到第三方切片，不归纳为本人稳定主张。

## 可以吸收的能力

1. **北疯式表达**：从现场细节取材，用意象、反差、幽默和适度夸张提升情绪张力。
2. **李洋洋式行动感**：减少被动猜测，用轻松、直接、可承担结果的方式表达兴趣和推进关系。
3. **共同底层**：短句、具体、有人味，敢于表达但允许对方不接。

## 必须过滤的部分

- 不把“拿下、套路、让人离不开”作为成功指标。
- 不把诗意、口才或高情绪强度误当承诺、可靠或关系质量。
- 不捏造经历、身份、财富、未来或稀缺性来制造吸引。
- 不把直播中的即时效果直接复制到严肃冲突、分手、安全或长期关系决策。
- 对方明确拒绝、僵住、回避或表示不适时立即降级，不用更强表达继续施压。

## 输出方法

先确定真实目的，再选择表达风格：

```text
真实意图 → 一句具体事实或欣赏 → 轻微意象/幽默 → 可退出的邀请
```

示例骨架：

> 刚才你认真讲那件事的时候挺吸引我的。周末要不要一起喝杯咖啡？不方便也没关系。

需要“北疯感”时只提高画面感和语言张力；需要“李洋洋感”时只提高直接度和行动感。始终保留用户本人口吻、对方选择权、适用条件和失败后的体面收线。
